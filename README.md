# C++ To-Do List

A simple command-line To-Do List application built using C++.

## Features

- Add new tasks
- View all tasks
- Mark tasks as completed
- Display pending and completed status
- Interactive menu

## Technologies Used

- C++
- Standard Template Library (STL)
- `vector`
- Structures and functions

## How to Run

Compile the program:

```bash
g++ -std=c++17 todo.cpp -o todo
```

Run it:

```bash
./todo
```

On Windows PowerShell, run:

```powershell
.\todo.exe
```

## Concepts Practiced

- Loops and conditional statements
- Vectors
- Structures
- Strings and user input
- Basic task management logic
